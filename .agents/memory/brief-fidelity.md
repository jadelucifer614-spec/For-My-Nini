---
name: Brief fidelity
description: A durable validation lesson for highly specified creative builds.
---

When a user provides detailed copy and interaction requirements for a creative experience, validate those requirements separately from visual quality after the first design pass.

**Why:** Visual delegation can produce a polished result while paraphrasing emotionally important copy or collapsing distinct interaction states.

**How to apply:** After the visual build, grep or inspect the source for exact required phrases and key state transitions, then make a focused correction pass before presenting the result.
