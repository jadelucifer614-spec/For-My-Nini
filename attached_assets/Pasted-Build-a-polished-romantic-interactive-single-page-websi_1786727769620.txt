Build a polished, romantic, interactive single-page website that is a surprise online date invitation for my girlfriend.

The website is for:

* Girlfriend: Nini, sometimes called Teddy
* Me: Fifi, sometimes called Teddy
* We met through playing BedWars on Roblox.
* We play Roblox, Among Us, and Scrabble together.
* One of our favorite things is simply talking about our day.
* The date should include playing whatever game she chooses, talking, and potentially watching a movie such as Toy Story or Spider-Man.
* Our color palette should be blue, white, and pink.
* The overall feeling should be cute, romantic, intimate, playful, and slightly funny.
* Do NOT make it look like a generic Valentine's Day template.
* Do NOT make it childish.
* It should feel like a modern, beautifully designed little interactive experience made specifically for one person.

IMPORTANT:
This is primarily a romantic frontend experience. Make it visually impressive and highly polished. Prioritize animations, transitions, typography, spacing, responsiveness, and the emotional progression of the experience.

TECH STACK:

* Use React.
* Use modern CSS or Tailwind CSS.
* Use Lucide icons or another lightweight icon library if useful.
* No backend/database is necessary.
* Everything should work locally in the browser.
* Make it fully responsive, especially for phones, because the recipient may open it on her phone.
* Do not require login.
* Do not create unnecessary authentication or backend infrastructure.

DESIGN:
Use a soft blue → white → pink gradient as the main visual language.

Suggested palette:

* Soft sky blue
* Very light blue
* White
* Soft baby pink
* Slightly deeper pink for accents
* Dark navy/blue text

Use:

* Large rounded cards
* Soft shadows
* Glassmorphism where appropriate
* Subtle gradients
* Rounded buttons
* Smooth page transitions
* Floating hearts
* Tiny stars/sparkles
* Very subtle background movement
* Beautiful typography
* Lots of whitespace

Avoid:

* Overly bright neon colors
* Clashing colors
* Huge amounts of emojis
* Generic stock-photo aesthetics
* Excessive animations that make the site annoying
* Anything that looks like a corporate website

The site should feel like opening a digital love letter.

Do not make this a traditional website with a navbar.

or a subtle progress indicator.

==================================================
MOBILE
======

This is extremely important.

Design mobile-first.

On phones:

* Cards should stack vertically.
* Buttons should be large enough to tap.
* Text should remain readable.
* Animations should remain smooth.
* No horizontal scrolling.
* No tiny controls.
* Make the main invitation fit nicely on a phone screen.

Also make it look excellent on desktop.

==================================================
AUDIO
=====

Do NOT autoplay music with sound.

If you want to include music, create a small optional music toggle.

Default state should be OFF.

The user should have to intentionally enable it.

If no audio file exists, do not create a broken player.
